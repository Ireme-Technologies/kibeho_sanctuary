## 8.5 Comparison note vs WordPress (qualitative)

| Factor | WordPress | This solution |
|--------|-----------|---------------|
| Familiarity | High for many editors | Training provided; similar “form + Save” UX |
| Plugin/theme licence churn | Common | No theme marketplace lock-in |
| ToR-specific modules | Custom plugins/theme work anyway | Built for Shrine modules |
| Hosting | PHP/MySQL | PHP/MySQL (same class of hosting) |
| Ownership | Site + DB; theme rights vary | Full application source + DB under Diocese |

A fair cost comparison should include **custom WordPress theme/plugin work** for the same ToR modules and multilingual setup—not only a cheap generic theme.
